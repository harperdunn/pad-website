## Adding a real flag video

The flag in these drafts is drawn in code as a stand-in. To use a real clip:

1. Download a free clip from Mixkit or Pexels (search "american flag waving", close up, 5 to 15 seconds).
2. Put it in `drafts/img/`, for example `drafts/img/flag.mp4`.
3. On the element that holds the flag canvas, add `data-video="img/flag.mp4"`. Or just ask Claude Code: "Use img/flag.mp4 as the flag in draft 1."
